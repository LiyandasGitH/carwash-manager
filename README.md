# Carwash Manager 

A java based carwash management system, that keeps track of services rendered, customers, and in the future payment services, payment systems, incorporating datebases into the system. 

## Project Structure 

```
src/main/java/com/carwash/
    model/
        Customer.java
        Employee.java
        Membership.java
        Payment.java
        Service.java
        Ticket.java
        Vehicle.java
    service/
        PaymentService.java
        TicketService.java
        ReportService.java
    ui/
        MainFrame.java
```
